# Mita Lite credit and authenticity policy

Official Mita Lite builds include the creator credit `blackbvnny`.

If that credit file is removed or altered, Mita Lite marks the installation as an unverified modified build and shows an authenticity warning. On an unverified build, wallpaper customization is disabled and the official Mita Lite wallpaper is kept in place. Linux itself, networking, package management, and other upstream software are not disabled.

A separately licensed build can be supported for Mita Lite-specific original branding, artwork, or custom components. Debian and other third-party/free-software components remain under their own upstream licenses and are not relicensed by this policy.

This mechanism is tamper detection and a limited desktop restriction, not an absolute anti-removal guarantee. A user with root access controls their Linux system and can modify local files or services. Official release signatures/checksums are the authoritative way to distinguish official builds from modified copies.

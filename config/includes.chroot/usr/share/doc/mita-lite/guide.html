MITA LITE / GET STARTED

A little setup.
A lot more play.

Your Xfce desktop is tuned for older x86-64 PCs. Effects are off, and the base avoids unnecessary extras. Install gaming clients and extra apps only when you need them.

Prototype build. This is a custom Debian 13 remix. Hardware, installer and game compatibility must be tested. There is no guarantee that every Windows game will run.

Hardware target: an older 64-bit PC with 2 GiB RAM for basic desktop/light gaming; 4 GiB is preferable. These targets are untested. Discord, browser tabs and modern games can need much more. 32-bit-only CPUs need a different base.

1. Connect and settle in

Use the network icon in the bottom panel for Wi-Fi or Ethernet. Set your keyboard, display scaling and time zone in Settings. Use the volume icon or PulseAudio Volume Control for your headset and microphone. If the PC has Bluetooth, add it through Game Hub before pairing devices.

If you booted from the live USB, your changes are temporary unless you configured persistence. For a lasting setup, test the live environment first, then reboot from the USB and choose the text-mode Install entry in its boot menu. Review its selected disk and partition changes before accepting. The Debian live installer is configured to copy the customized desktop.

2. Open Game Hub

The controller launcher on the panel opens Game Hub. Click an app to open its installer in a terminal. It asks before continuing, then APT displays dependencies and disk requirements for your review. Close the terminal once it says Done.

For more software, open Synaptic Package Manager. The base avoids Snap and Flatpak runtimes to save space, but Debian packages let you add them later if an app needs them. Do not add Ubuntu PPAs to Debian.

3. Set up Steam and check your games

Open Steam, sign in and let the client update. Check Settings → Compatibility for the available Steam Play/Proton options. For an individual title, use Properties → Compatibility to select a Proton version if needed. Start with Valve's default before trying other versions.

Check the game's publisher support information and ProtonDB community reports. Reports are hints, not guarantees for this PC. Some anti-cheat-protected multiplayer games cannot run on Linux; the game's developer must enable compatible support. A custom distro cannot remove that limitation.

After installing GameMode with mita-apps gamemode, an optional Steam launch option is:

gamemoderun %command%

With MangoHud installed:

mangohud gamemoderun %command%

These tools are optional. Disable the overlay if it interferes with a game. GameMode cannot overcome a GPU, CPU or memory bottleneck.

4. Match the graphics driver to your hardware

The base uses Mesa OpenGL and does not require Vulkan. Start by checking that OpenGL reports the physical GPU instead of software rendering:

glxinfo -B
lspci -nnk

For a Vulkan-capable GPU, install Vulkan tools in Game Hub and run vulkaninfo --summary. Installing these packages cannot give an unsupported GPU Vulkan capability.

For some older DirectX 9–11 games on non-Vulkan hardware, try this per-game Steam launch option:

PROTON_USE_WINED3D=1 %command%

This selects WineD3D/OpenGL instead of DXVK. It is not a DirectX 12 solution and can be slower or incompatible. See Valve’s runtime options. Native, 2D and older Linux games remain the first choice for weak hardware.

NVIDIA: choose the driver for the exact GPU model using the Debian NVIDIA guide. Proprietary drivers and matching 32-bit libraries need separate setup. Secure Boot may require enrolling a module-signing key. Avoid installing an arbitrary driver branch or NVIDIA's standalone .run file. Hybrid laptops also need offload testing.

Very new GPUs may require newer firmware, kernel or Mesa packages. Diagnose the hardware before changing repositories; do not mix Debian stable and unstable as a quick fix.

5. Keep memory and disk use low

  • Close the browser and Game Hub while playing. Keep Discord and Steam auto-start disabled unless you need them.
  • Game downloads, shader caches and Proton runtimes need additional space. Inspect Steam's Storage settings before removing games or caches.
  • Use the Task Manager to see what is using RAM. Compressed zram swap helps memory pressure but is not extra physical RAM.
  • Desktop compositing and GTK animations are already disabled. You can enable compositing in Settings → Window Manager Tweaks → Compositor if the GPU handles it well; it may help tearing at an extra resource cost.
  • The installer may allocate disk swap as well as zram. Review its storage summary; hibernation needs a separate, correctly configured disk-backed setup.

6. Updates and troubleshooting

Use Update system in Game Hub for Debian packages. Review its change list, then reboot after kernel or driver updates. Steam manages its client and games; Discord's downloaded .deb needs separate updates through its Hub installer. Custom Mita configuration files have no automatic upstream updater.

For silent audio, select the correct output and input in PulseAudio Volume Control. For Discord screen sharing or OBS encoding problems, verify the native driver and test the exact capture workflow. For game problems, record the game name, GPU, driver, Proton version and any error message.
